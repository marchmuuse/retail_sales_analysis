# Аналитический кейс по исследованию розничных продаж

## О проекте

Учебный аналитический кейс на основе исторических данных о розничных продажах за период с января 2013 года по октябрь 2015 года.

Цель проекта — исследовать динамику продаж, результаты магазинов и товаров, выявить основные закономерности и сформировать практические рекомендации.

## Что было сделано

- проверка и подготовка данных в Python;
- исследовательский анализ продаж;
- SQL-анализ в SQLite;
- построение модели данных;
- разработка интерактивного дашборда в Power BI;
- расчёт показателей с использованием DAX;
- моделирование бизнес-процесса в BPMN;
- формирование выводов и рекомендаций.

## Инструменты

**Python · Pandas · Jupyter Notebook · SQL · SQLite · Power BI · DAX · BPMN**

## Структура проекта

- `python/` — анализ данных в Python;
- `sql/` — SQL-запросы;
- `powerbi/` — файл Power BI;
- `bpmn/` — модель бизнес-процесса;
- `report/` — итоговый аналитический кейс в PDF.

## Источник данных

[Kaggle — Predict Future Sales](https://www.kaggle.com/competitions/competitive-data-science-predict-future-sales)

Датасет содержит исторические данные о розничных продажах. Данные предоставлены 1C Company.

## Результат

В результате создан аналитический кейс полного цикла:

**данные → подготовка → анализ → SQL → Power BI → бизнес-выводы → рекомендации**
